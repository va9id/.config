# Apple Shortcuts/Scriptable

## Usage

- Download [Scriptable](https://apps.apple.com/us/app/scriptable/id1405459188) from the App Store
- Setup file bookmark in Scriptable and name it what you like
    - Update variables `<bookmarkName>` and `<fileName>` respectively in `habitTracker.js`
- If you want to click on widget and make it track your habits do the following:
    - Create Apple Shortcut and make it do what you like
    - Update the variable `<SHORTCUT_NAME>` in `habitTracker.js`
    - Click on the Scriptable widget and set `When Interacting = Run Script`
